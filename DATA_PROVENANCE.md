# Data Provenance and Redistribution Notice

## Source

The raw and derived material records in this repository originate from the Materials Project summary API.

Recorded extraction context:

- API family: Materials Project summary API;
- API version observed during extraction: `0.87.2.dev4+g6bd8ed856`;
- pilot size: 3,000 records;
- additional stress-test pool: 1,000 records;
- extraction and sampling details: `raw/MANIFEST.json` and `raw/STRESS_POOL_MANIFEST.json`.

## Credentials

No Materials Project or GitHub access token is stored in the repository. Download scripts read credentials from process environment variables.

## Attribution and terms

Materials Project data remain attributable to Materials Project and its underlying contributors. Users of redistributed records should review and comply with the current Materials Project terms, attribution requirements and recommended citations before reuse.

This repository is an independent methodological experiment and is not an official Materials Project product or endorsement.

## Scope

The included 3,000-record pilot is a deterministic stratified cluster-window sample, not a uniform sample of the entire Materials Project. Reported family proportions are not population estimates.
